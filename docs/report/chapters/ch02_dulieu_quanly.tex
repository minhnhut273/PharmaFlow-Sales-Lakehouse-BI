\section{Mô hình Lưu trữ Đa Tầng và Bảo mật}
\begin{itemize}[leftmargin=1.5em]
  \item \textbf{Lưu trữ phân tán theo cấu trúc dữ liệu:} PostgreSQL đảm nhiệm dữ liệu giao dịch/tổng hợp có quan hệ chặt chẽ; MongoDB Atlas lưu tài liệu JSON bán cấu trúc có độ sâu biến thiên; Amazon S3 giữ nguyên vẹn bytes JSON thô từ API thời tiết kèm manifest \texttt{accepted.json} và checksum SHA-256 bất biến (\textit{S3 Object Lock / Versioning}).
  \item \textbf{Tầng Lakehouse (Databricks Delta):} Tầng \textbf{Bronze} lưu bản sao thô giữ nguyên lược đồ nguồn; \textbf{Silver} tách riêng \texttt{fact\_sales\_line} và \texttt{fact\_sales\_observation}, chuẩn hóa \texttt{local\_date} theo múi giờ từng cửa hàng; \textbf{Gold} tạo 4 Data Mart (\texttt{mart\_sales\_daily}, \texttt{mart\_sales\_weather\_daily}, \texttt{kpi\_sales\_trend}, \texttt{mart\_sales\_observation\_period}) dung lượng \texttt{449 MB} trên Neon BI Mirror.
  \item \textbf{Quản lý mật khẩu và phân quyền:} Toàn bộ chuỗi kết nối nằm trong tệp \texttt{.env} cục bộ (bị chặn bởi \texttt{.gitignore}) hoặc AWS SSM \texttt{SecureString}; Dashboard Streamlit chỉ sử dụng vai trò chỉ đọc \texttt{SELECT} (\texttt{bi\_reader}) trên schema \texttt{quick\_gold\_md01}.
\end{itemize}
